# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| `0.4.x` | Yes |
| `< 0.4.0` | No |

## Scope & Engineering Disclaimer

This repository provides a mathematical optimization and power-systems economics simulation framework (`energy_model`) built on `PyPSA` and `HiGHS`. It does **not** interface with live SCADA, EMS, market-clearing engines, or physical grid infrastructure, and its outputs are **not** real-world investment advice or regulatory compliance certification.

## Reporting a Vulnerability

If you discover a security or data-handling defect (for example, unsafe file parsing or dependency vulnerabilities), please open a private security advisory on GitHub (`Security -> Advisories -> Report a vulnerability`) rather than posting an exploit publicly. Reports are reviewed promptly with a target response window of 7 days.
